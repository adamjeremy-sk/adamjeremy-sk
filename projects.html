Vermilion Editor

Vermilion Editor is a native Linux code editor, written in C++17 directly against the C interfaces of GTK 4 and GtkSourceView 5, for developers who work alongside an AI agent and would rather keep editing, review, compilation and debugging inside one application than spread them across several. The agent operates through the editor's own tools, within permission presets the user configures, and every turn it completes is recorded as a change set that can be compared side by side and reverted one hunk at a time. A local llama.cpp server is supported as a first-class endpoint, commercial providers are accessed with the user's own API keys, and the editor collects no telemetry of any kind.

The project also contains CTXMon, a native C++ reimplementation of my original Python utility for monitoring llama.cpp servers while they are generating. By polling each server's /slots and /props endpoints and parsing its log output, CTXMon reports context utilization, generation and prompt-processing speed, recent requests and GPU memory, and it issues warnings as the context window approaches its limit. It will be available both as a panel inside the editor and as an independent program, and its interface-independent core, which is the current development milestone, is tested against the output of the original Python implementation.

WeatherAPP Libre

WeatherAPP Libre is a weather and natural-light planning application for Android, designed for photographers, anglers, hunters and amateur astronomers whose plans depend on more than the daily high and the chance of rain. It requests no location permission, relying instead on cities the user selects manually, and it contains no advertising, user accounts or behavioural analytics. Users can choose among five numerical forecast models and receive current conditions, 36-hour hourly and seven-day forecasts, and additional detail on air quality, ultraviolet exposure and wind.

Its astronomical features calculate Golden and Blue Hour, lunar phases and a multi-year lunar calendar, periods of true astronomical darkness, night visibility and solunar activity, using methods adapted from Jean Meeus's Astronomical Algorithms. Official alerts from Environment and Climate Change Canada and Europe's MeteoAlarm network are available on an opt-in basis, and home screen widgets refresh from a shared cache instead of polling independently. Additional themes and forecast providers can be installed through declarative extension manifests.
